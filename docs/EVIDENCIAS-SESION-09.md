# Evidencias - Sesión 09

La guía solicita:

1. Precio formateado en Android.
2. Precio formateado en iOS.
3. Selector nativo de compartir en Android.
4. Hoja nativa de compartir en iOS.
5. Error del punto de control 1 cuando existe el expect y falta un actual.

## Punto de control 1

Para obtener la evidencia, renombrar temporalmente `Formato.android.kt`, compilar Android y capturar el error que indica que falta la declaración actual. Después restaurar el archivo.

## Android

1. Abrir el proyecto en Android Studio.
2. Ejecutar `androidApp`.
3. Entrar a Productos.
4. Abrir un producto.
5. Pulsar **Compartir**.
6. Capturar el selector nativo.

## iOS

Se necesita macOS + Xcode. Ejecutar `iosApp`, abrir un producto y capturar la hoja nativa de compartir.
